Temma Mount Driver

Version 1.0.30 · ASCOM driver for Takahashi Temma and Temma 2 mounts.

Download Windows MSI installer

Install or update

Install ASCOM Platform first. Close N.I.N.A. and other ASCOM clients. If a previous Temma driver is installed, uninstall it through Windows Installed Apps or Control Panel before running this MSI. Approve administrator access when prompted.

The installer registers the driver automatically. In N.I.N.A., select CCDAstro Temma Mount Driver and open Setup to choose your COM port and mount settings.

Uninstall and reinstall

Uninstall removes the program files and COM registration while preserving your ASCOM settings. A saved driver listing may remain in an ASCOM client after uninstall; reinstall the driver before using it again.

Supported mounts

EM-11, EM-11 Temma 2M, EM-200, EM-200 Temma 2M, NJP, EM-400 and EM-500.
